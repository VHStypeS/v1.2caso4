# Upgrader 1.4.0 (Forge 1.20.1)

## Что нового в 1.4
- **Крафт зелья +podkrytka на верстаке**: `NDN / DBD / .F.` (N незеритовый слиток x2, D алмазный блок x3, B стеклянная бутылка, F ферментированный глаз паука).
  Варка в зельеварке осталась как раньше.
- **В чат попадают только ЛЕГЕНДАРНЫЕ предметы** (редкость предмета внутри ящика), и без цифр шансов. Просто «маленький шанс» больше не повод
  для объявления. Тексты: `config/upgrader/messages.json` -> `legendary_item` (старый файл с шансами заменится один раз).
- **Редкости предметов**: Обычный / Необычный / Редкий / Эпический / Легендарный. Хранятся в файле ящика (`"rarity"`), в редакторе меняются кликом по названию редкости.
- **Рандом по правилам баланса**: из пачки случайных предметов 33% самых частых (Обычные) и 10% Легендарные (остальное между ними).
  Доля выпадения по классам: 55 / 24 / 13 / 6 / 2 % (константы в `LootBalance`). Внутри класса слабее/дешевле = чаще.
- **Что считается редким**: сложность крафта; у оружия и инструментов урон (дерево 4 ... незерит 8, модовые 20-30 очень редкие); у брони суммарная защита
  материала; у книг зачарование и уровень (починка, защита V+ редкие).
- **Тиры ящиков**: common = дерево..алмаз (и равное по урону/броне); mid = железо..незерит; rare = от железа и выше без потолка;
  legendary = от алмаза; mythic = от незерита. Работает для «Рандом», «+ Из мода» и книг. Ручной выбор («+ Предмет», «+ Из руки») не ограничен.
- **Книги**: «Книги x5/x15» (случайные в рамках тира: common до II, mid до IV, rare и выше любые, в т.ч. Protection V+ с Apotheosis, Mending) и «+ Книга (выбрать)» с выбором уровня до максимума зачарования.
- **Кнопка «Авто-баланс»** пересчитывает весь ящик по правилам (33% / 10%, итого 100%).
- **Новая рулетка**: два кольца предметов вокруг ядра с рунами, звёздные полосы, ауры по редкости у каждого предмета, вспышка, ударные волны,
  вращающиеся лучи, конфетти и тряска экрана для Эпических/Легендарных, карточка результата. ESC — пропуск.
- Версия сети 4: jar обновить и на сервере, и у всех клиентов.

## Что нового в 1.3
- **Рулетка по орбите**: предметы крутятся вокруг ящика, замедляются, приз останавливается спереди и вылетает в центр. ESC — пропуск.
- **Новый дизайн** всех окон: просмотр шансов (карточки со свечением и шансом под предметом), редактор, выбор предметов, апгрейдер.
- **Апгрейдер** (блок): ставишь N ящиков -> с шансом получаешь ящик уровнем выше (см. ниже).
- **Зелья удачи ящиков** (крафт на верстаке): 2 минуты повышенного шанса РЕДКИХ предметов из ящиков.
- **Редактор**: кнопки «Рандом 10/30/100», «+ Из мода» (целый мод сразу), «½» и «×2» у каждого шанса. Шансы считаются по
  сложности крафта (по рецептам, которые знает клиент: ваниль + все моды): больше этапов и дороже сырьё = реже.
  Стакающиеся предметы получают количество 1..размер стака (64/16), остальные — 1.
- Шансы с мобов: **common 40%, mid 25%, rare 10%**. Лимит убийств зелья +podkrytka **выключен** (`kill_limit` = 0): с фармилки падает.
  Старый `drops.json` автоматически переносится один раз (в нём ставятся новые шансы мобов и kill_limit = 0).

## Апгрейдер
Блок `upgrader:upgrader` (крафт на верстаке: обсидиан, железные блоки, алмазы, сундук). ПКМ -> окно: выбери маршрут (`<` `>`),
количество (−10/−1/+1/+10, МИН/МАКС), смотри шанс, жми «УЛУЧШИТЬ». Ящики сгорают, при успехе выдаётся 1 ящик цели.
Настройка: `config/upgrader/upgrade.json`:
- `chances`: по умолчанию 20 шт -> 20%, 30 шт -> 40%, 64 шт -> 75% (между точками линейно);
- `routes`: по умолчанию common -> rare, mid -> legendary, rare -> mythic. Можно менять, в т.ч. на свои ящики;
- `min_amount` 20, `max_amount` 64, `result_amount` 1.
Сервер сам проверяет количество ящиков в инвентаре и бросает шанс.

## Зелья удачи ящиков
- `upgrader:luck_potion`: сетка ` E ` / `GBG` / ` D ` (E изумруд, G золотой слиток, B стеклянная бутылка, D алмаз).
- `upgrader:luck_potion_greater`: без формы: зелье удачи + алмазный блок + изумрудный блок + светящаяся пыль.
- Эффект «Удача ящиков» 120 сек (`luck.duration_seconds`). Предметы, у которых базовый шанс < 10% (`luck.affects_items_below_percent`),
  получают вес × (1 + 25%) (`luck.boost_percent`), у большого зелья +60% (`luck.greater_boost_percent`). Пример: 0.8% -> 1%.
  Остальные шансы пересчитываются, итого по-прежнему 100%. В окне просмотра шансы уже показываются с учётом удачи.

## Редактор: как работают шансы по сложности
`Complexity` берёт рецепты клиента: сырьё (доски, булыжник) стоит 1, алмаз 24, обломки незерита 40 и т.д.; крафт стоит
сумма ингредиентов / количество на выходе + 0.6 за этап. Вес = 100 / стоимость^1.5. Пример: доски — обычные, незеритовый меч — в тысячи раз реже.
Нужно зайти в мир (рецепты синхронизируются с сервером), редактор открывается командой `/upgrader edit <ящик>`.



## Сборка jar
Способ 1, ничего не ставить: залей содержимое папки на GitHub (новый репозиторий), вкладка
Actions -> build -> Run workflow, потом скачай artifact `upgrader-jar` (внутри `upgrader-1.2.0.jar`).
Способ 2, локально: JDK 17 + IntelliJ IDEA, открой папку как Gradle-проект, задача `build`, jar в `build/libs/`.
Jar кладётся в `mods` и сервера, и ВСЕХ клиентов (версия сети изменилась, старый 1.0.0 с новым не уживётся).

## Как открывается ящик
1. ПКМ по ящику -> окно со всем содержимым и РЕАЛЬНЫМИ шансами (видно любому игроку).
   Наведи на предмет: название, количество и шанс. Чем реже — тем краснее, чем чаще — тем зеленее.
2. Кнопка «Открыть» снизу -> рулетка. Приз выбирает сервер.
3. Предмет попадает в инвентарь только ПОСЛЕ окончания рулетки (или после пропуска по ESC). Если игрок вышел/закрыл окно/сервер
   останавливается — приз выдаётся сразу, ничего не теряется.
   ESC во время рулетки — пропустить анимацию. После неё: «Открыть ещё» / «Закрыть».
4. `/upgrader view <ящик>` — посмотреть содержимое без предмета (для всех).

## Чат-оповещения
Всем уходит сообщение ТОЛЬКО когда выпал предмет редкости «Легендарный» (после анимации, чтобы не спойлерить). Шансы в чат не пишутся.
Тексты: `config/upgrader/messages.json` (`legendary_item`), плейсхолдеры `{player} {item} {count} {crate}`.

## Свои ящики
- `/upgrader create <id> <модель> [название]` — новый ПУСТОЙ ящик. Модель: common|mid|rare|legendary|mythic.
  Пример: `/upgrader create lol_podkrytka mid lol podkrytka`
- `/upgrader edit <id>` — наполнить (пароль -> редактор).
- `/upgrader give <игрок> <id> [кол-во]` — выдать. Работает и из командных блоков.
- `/upgrader open <игрок> <id>` — открыть сразу с рулеткой, без предмета (для интерактивов, квестов, NPC).
- `/upgrader rename <id> <название>`, `/upgrader delete <id>`, `/upgrader list`.
Все ящики (и встроенные) редактируются одинаково. Файл лута: `config/upgrader/<id>.json`.

## Редактор
- «+ Предмет (все моды)»: сетка ВСЕХ предметов с поиском (название, id, `@мод`), клик = добавить/убрать.
- «+ Из руки» — для предметов с NBT (зачарованные, зелья, и т.п.); количество в руке = мин/макс.
- Колонка «Реально» и цветная полоска — настоящий шанс, который увидят игроки.
- «Авто-100%»: введи шанс одному предмету и нажми Enter — остальные пересчитаются так, чтобы итого было 100%.
- «Поровну», «К 100%», «Сортировка», поиск по ящику.

## Зелье +podkrytka
`/give @s upgrader:podkrytka` или вкладка Upgrader в креативе. Эффект 1 минута (`podkrytka.duration_seconds`):
каждое убийство монстра/босса игроком = 0.1% на Legendary Crate (`podkrytka.legendary_chance_percent`),
ящик падает прямо в инвентарь и объявляется в чате. Те же правила честности, что ниже.

**Лимит убийств зелья +podkrytka (в 1.3 ВЫКЛЮЧЕН по умолчанию, `kill_limit` = 0):** если включить, после N убийств за зелье (`podkrytka.kill_limit`)
шансы РЕЗКО падают до фиксированных (без постепенного снижения, ящики продолжают падать, просто очень редко):
common 10% -> 2.5%, mid 4% -> 0.5%, rare 1% -> 0.02% (`limited_mob_drop_chance_percent`), легендарка от зелья 0.1% -> 0.0004%
(`limited_legendary_chance_percent`). Шансы боссов не меняются. Счётчик сбрасывается, когда зелье выпито заново (не продлено).

### Крафт в зельеварке (бутылки снизу, ингредиент сверху)
1. Бутылка воды + ферментированный глаз паука -> основа 1/2
2. Основа 1/2 + 3 алмазных блока (кладутся стопкой сразу) -> основа 2/2
3. Основа 2/2 + 2 слитка незерита (стопкой) -> зелье +podkrytka (1 минута)
4. Зелье +podkrytka + 32 пороха (стопкой) -> взрывное +podkrytka (обычное splash-зелье, эффект получают все в радиусе)
Количества: `podkrytka.brew_diamond_blocks`, `brew_netherite_ingots`, `brew_gunpowder`. Стоимость берётся за ОДНУ варку (1-3 бутылки сразу).
Внимание: рецепт воды + глаза паука теперь даёт основу, а не Weakness (ванильный Weakness из бутылки воды больше не сварить).

## Дропы строго «от рук игрока» (config/upgrader/drops.json)
- Фейк-игроки (дефлекторы, турели, Create-деплойеры и т.п.) не считаются (`require_real_player`).
- Мобы из спавнеров ничего не дают (`block_spawner_mobs`).
- Игрок сам должен нанести минимум 50% здоровья моба (`min_player_damage_percent`):
  убийства лавой/падением/кактусами/ловушками с добиванием тычком не считаются.
- Обычные монстры: common 40%, mid 25%, rare 10% (на землю). Боссы: legendary 20%, mythic 0.4% (в инвентарь).

## Сундуки данжей
Common (8%) и Mid (3%) добавляются в сундуки структур (`dungeon_chest_chance_percent`, ТОЛЬКО эти два тира).
Список таблиц — `dungeon_loot_tables`, в конце можно ставить `*`: `"somemod:chests/*"`.
Изменения применяются после перезапуска мира или `/reload`.

## Конфиги (config/upgrader/)
`common|mid|rare|legendary|mythic.json`, `<id своего ящика>.json`, `custom_crates.json`, `drops.json`,
`messages.json`, `auth.json` (SHA-256 пароля редактора). `/upgrader reload` перечитывает всё.

## Если мода предмета нет
Запись игнорируется при выпадении (из файла не удаляется), шансы остальных пересчитываются пропорционально.
